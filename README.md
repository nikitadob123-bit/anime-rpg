# Лира Пепла — RPG-PWA

Тёмная фэнтези-RPG в аниме-стиле. Чистые HTML/CSS/JS без сборки, офлайн через service worker, портретная мобильная вёрстка (390×844), русский интерфейс. Мир, герои и сюжет — оригинальные.

**Играть:** https://nikitadob123-bit.github.io/anime-rpg/ (можно «Установить» как приложение).

## Что внутри
- **Профили**: ник + аватар, 3 слота героев, версионированные сохранения в localStorage, резервная копия, экспорт/импорт кодом `ARPG3.…`, миграции v1→v2→v3.
- **Создание героя** (7 шагов с живым предпросмотром): имя/пол, 5 рас (бонусы + расовый пассив), 5 классов (Воин, Маг, Вор, Целитель, Щитоносец), 30 портретов (5 рас × 2 пола × 3), «Эхо Лиры» (10 уникальных навыков с деревьями по 7 узлов), основная и дополнительная профессия (навсегда, с подтверждением).
- **Древа развития**: 82 узла на 5 классов (3 ветки, ярусы, предусловия, ранги, уровни) + 70 узлов у уникальных навыков.
- **9 профессий** (кузнец, алхимик, зачарователь, кожевник, повар; шахтёр, травник, охотник, рыбак), 84 рецепта, промысел, перки 5/10/15/20.
- **Сюжет**: пролог + глава 1 + глава 2 (≈4 800 слов в одной ветке), выборы с флагами, катсцены с эффектами.
- **6 подземелий × 4 сложности**, пошаговый бой по шкале скорости, стихии и реакции, статусы, телеграфируемые атаки боссов, лут 5 редкостей, лавка, кузница, таверна.
- **Звук** — синтез WebAudio (переключатель), частицы на canvas.

## Разработка
```
npm install        # только playwright-core для e2e и иконок
npm test           # юнит-тесты логики (node)
npm run sim        # симулятор баланса → docs/sim-report.json
npm run e2e        # headless Chrome 390×844, скриншоты в shots/
npm run serve      # локальный сервер
npm run portraits  # перегенерация портретов (процедурный SVG → webp)
npm run icons      # иконки из icons/*.svg
```
Портреты нарисованы процедурным SVG-генератором (`js/portrait.js`) и отрисованы в WebP (`tools/gen-portraits.js`); ИИ-генерация изображений не использовалась. Если файл портрета не загрузился, игра рисует его SVG на лету.
Для обновления у игроков меняйте `VERSION` в `sw.js`.
