# Нимб Мира — RPG-PWA с визуальной новеллой

Тёмная фэнтези-RPG в аниме-стиле: вы — пробудившийся **Король Демонов**. Энтропия Реальности стёрла ваш город и сестру Лирию; цель — убить Апостола Света Люмиэля, открыть Врата Богов и взять артефакт воскрешения. Чистые HTML/CSS/JS без сборки, офлайн через service worker, портретная ориентация 390×844.

**Играть:** https://nikitadob123-bit.github.io/anime-rpg/ (можно «Установить» как приложение).

## Что внутри
- **Король Демонов вместо классов**: 5 «прошлых» (происхождений), 6 **Веток Силы** (Фактор Короля Демонов, Плоть и Мощь, Тьма и Разрушение, Энтропия, Власть и Подчинение, Проклятия и Пожирание) — 98 узлов, 12 концептуальных, слияние узлов в эволюцию, 2 очка за уровень.
- **Концептуальные навыки**: Мантра Силы (каждый ход боя атака/защита ×2 от значений до боя, кап 3 стака, сброс после боя), Пустота Забвения, Бездонная утроба, Бессмертный Король, Кулак, ломающий небо, и ещё 8 активных c_*.
- **Свита**: 6 подчинённых, 9 генералов, 3 пощажённые героини Света. Уровни, опыт, экипировка, верность (4 тира), разговоры, подарки, задания в реальном времени, отряд до 3, ручное/авто командование в бою.
- **Сердца**: 12 героинь, симпатия, 3 сцены на каждую (пороги 15/40/70), свидания, постоянные бонусы. Только SFW.
- **Визуальная новелла**: полноэкранные сцены, CG, крупные портреты по настроению (neutral/happy/angry/shy/sad + настроения героя), кроссфейд, дыхание, до 3 персонажей с затемнением неактивных, лог, авто/пропуск, эффекты (тряска, вспышка, энтропия, ореол, тишина). Сюжет ≈ 6 200 слов + ≈ 2 200 слов романтики; дуэли с героинями Света и выбор «пощадить/убить».
- Профили, 3 слота, версионированные сохранения (v4, миграция v1→v4), экспорт/импорт кодом, 9 профессий, 6 подземелий × 4 сложности, пошаговый бой по шкале скорости.
- **Почта** (v2.9.0): письма с подарками. Игра офлайн, но с интернетом скачивает ленту `mail/inbox.json` с GitHub Pages; подарок по каждому письму — один раз. Свои письма игры (приветствие, награда за арку) — без сети. Как отправить письмо: [docs/MAIL.md](docs/MAIL.md), `node tools/mail.js add …`.
- **Редкости снаряжения** (v2.10.0): 11 ступеней — Обычный, Необычный, Редкий, Уникальный, Эпический, Легендарный, Мифический, Божественный (выпадают), Концептуальный, Исток, До существования (ещё не открыты). Редкость задаёт число и силу статов, линий характеристик и аффиксов, особые свойства (✦/✸/☀), цену, стоимость и предел улучшения. Шанс высоких редкостей растёт с уровнем контента и на боссах. Справка — кнопка «?» в снаряжении. Сохранения v6 (миграция старых 0…4).
- **Клинки Истока** (v2.13.0): три уникальных меча редкости «Исток» (ур. 55, +0/13) — «Клинок Первопричины», «Клинок Нулевого Закона», «Клинок Первого Разделения». Пять общих свойств редкости: Отрицание бессмертия, Иммунитет к концепциям, Приоритет Истока (дебаффы предметов ниже Истока не действуют), Стирание Истоком (убитый враг не появляется на этом этапе 10 минут реального времени; полностью стёртый этап очищается сам без наград; сюжетные дуэли не стираются), Общий приоритет. Новый тип урона — Разделяющий. Только письмом (`--unique prime_cause,zero_law,first_division`). Порядок силы: Энтропия < Первопричина ≈ Нулевой Закон < Первое Разделение (`node tools/concept-duel.js`, герой ур. 55). v2.13.1: Нулевой Закон получил «Получаемый урон −40%».
- **Концептуальные клинки** (v2.12.0, баланс v2.12.1: Исток ≈ Пламя, Исток — самый живучий по получаемому урону, `node tools/concept-duel.js … --tank`): ещё шесть уникальных мечей — «Тьма Бездны», «Сердце Преисподней», «Пламя Первого Пожара», «Безбрежный Исток», «Хронос», «Конец Всего — Клинок Энтропии» (Распад, Тепловая смерть, Горение, откат времени, шкала хода); только письмом `{unique:id}` (`node tools/mail.js ids`). Баланс: `node tools/concept-duel.js`.
- **Уникальные предметы** (v2.11.0): первый Концептуальный меч «Свет Эдема» (Атака +1000, ✧ концептуальные свойства и навык). Не выпадает и не создаётся — только личным письмом (`unique` + `to: [код игрока]`, см. docs/MAIL.md). Код игрока `NM-XXXXXX` — во вкладке «Почта» и в «Меню».

## Сюжет на 300 глав
План: 30 арок × 10 глав (главы 1–3 — старые сцены, арка 1 написана целиком: главы 1–10). Документы: [`docs/STORY_SPEC.md`](docs/STORY_SPEC.md) (формат и длина главы, контракт `RPG.D.CHAPTERS[n]`), [`docs/STORY_BIBLE.md`](docs/STORY_BIBLE.md) (канон, персонажи, стиль, 30 арок). Машиночитаемый план — `js/story/outline.js`. Арки грузятся лениво (`js/story/arcNN.js`), во вкладке «Сюжет» — арки → главы, прогресс и рекомендуемый уровень.
```
npm run lint:story   # формат, id, длина, русский язык, запрещённый контент, outline
npm run stats:story  # длина глав vs эталон (≈96 реплик, ≈8 900 знаков)
npm run e2e:story    # e2e сюжета (вкладка «Сюжет», главы 4–10, вылазки)
node tools/gen-bible.js  # обновить разделы арок в STORY_BIBLE.md из outline.js
```

## Арт
Исходники кладутся в `/workspace/vn-art` как `<id>_<mood>.jpg|png` (`cg_*` — CG). `tools/import-art.sh [папка]` вырезает фон и пишет `assets/vn/*.webp` + `manifest.json` (его читают игра и service worker). Если PNG уже с настоящей альфой — вырезание пропускается. Метод (tools/matte.py): нейро-маска isnet-anime (rembg/onnxruntime; запасные u2net, birefnet, готовые маски в `tools/data/masks`) → trimap → closed-form matting (pymatting) даёт мягкую альфу волос/рогов/крыльев → `estimate_foreground_ml` вычитает цвет серого фона из полупрозрачных краёв (defringe) → чистка островков; границы кадра, которых касается персонаж, плавно растворяются, низ бюста уходит под окно диалога и гаснет CSS-маской (без синтетического продления пикселей). `tools/geom.py` находит центр и ширину лица (каскад lbpcascade_animeface + совмещение силуэтов настроений) — по ним плеер выравнивает размер голов и совмещает настроения. Окружение: `python3 -m venv --system-site-packages .venv-matte && .venv-matte/bin/pip install "rembg[cpu]" opencv-python-headless==4.11.0.86` (без него — запасной chroma-ключ). Контактные сводки: `tools/contact-sheet.py` → `shots/portraits-{dark,light}.jpg`. Нет файла настроения — откат на `neutral`, нет арта вовсе — запасной SVG-образ (`js/portrait.js`).

## Разработка
```
npm test           # юнит-тесты (node) + тесты сюжета (test/story.js)
npm run sim        # симулятор баланса → docs/sim-report.json
npm run e2e        # headless Chrome 390×844, скриншоты в shots/
npm run serve      # локальный сервер
tools/import-art.sh  # импорт арта из /workspace/vn-art
```
Для обновления у игроков меняйте `VERSION` в `sw.js`.
