# Арка 9 «Железные Горы Кархола» (главы 81–90) — автор w2

## Что произошло
- 81: Врата Кархола. Стража (десятник Бурлим), пароль — имя клана. Выбор → `brum_wait` / `brum_joke` / `wall_punch`. Брум вслух: «Клан Кованого Корня! Брум, сын Бразга, внук Мастера Горна». Врата открыты, в городе всё узнают.
- 82: Подгорный пир. Гарм выигрывает конкурс по еде, Король — по неподвижности (диван на табурете). Выбор → `brum_sofa` / `king_sofa`. Чей-то шпион в тёмной сутане наблюдает.
- 83: Великий Горн. Нокс и Касси по чертежу: куют цепь «Новая Печать — вторая цепь для удержания Светила». Лифт-клеть, Касси в чане с маслом. Выбор → `asked_helg_direct` / `smith_scouting`.
- 84: Малая кузня Брума. Король рассказывает о Лирии; Брум куёт железный колокольчик из нимбового металла; закалка слезой Короля. Ставится `skill_smith`. Выбор → `brum_thanks_plain` / `brum_court_smith` (придворный кузнец). Розовый потолок от зелья Тика.
- 85: Хельдгрим Железносердый (король-под-горой, 600 лет). Канцелярия гномов. Хельдгрим: Печать ветшает, нужен Хранитель; Брунхильд предлагает себя, он смотрит на Короля. Выбор → `helg_open` / `helg_refused` / `helg_alt`. Три дня на решение.
- 86: ночь на площадке над кузнечным ярусом. Брунхильд: «Я устала». Обещание сварить грибной суп. Выбор → `brun_held_hand` (aff +5, зовёт его Арата) / `brun_cloak` / `brun_stay`. Рота подслушивала.
- 87: Совет Мастеров тянет время (Брум проверял цепь). Ошибка: любое звено, тронутое живым, считает его Хранителем. Бой со Стражем Печати «Сотня Молотов» (`hammer_hall`). Выбор → `helg_confronted` / `masters_thanked`.
- 88: Главный контур. Касси нечаянно подстроила частоту рун. Лазейка в чертеже (оставил Аурелий): Хранителем может быть Ключ. Король узнаёт почерк «Мы подождём». Выбор → `seal_fix` (лазейка открыта) / `seal_close`.
- 89: Сердце Горы. Хельдгрим пытается приковать Короля; тот подсовывает цепи чертёж, цепь бьёт старика. Бой (`mountain_heart`), дуэль → `helg_persuaded` (3 месяца, ставится `arc9_helg_alive`) / `helg_slain` (`arc9_helg_dead`). Лирия: «Звенья-завтраки».
- 90: на обороте чертежа — Ключ Нити (`has_thread_blueprint`): нимбовый металл, ножнового серебра и «слеза, пролитая добровольно». Ильвара: Ключ может отпустить Нимб вверх или уронить вниз. Свадьба Гарма и орчихи Гурры (поварихи, едет с Ротой). Брум остаётся кузнецом Кархола и делает Ключ. Молот Брума — Королю. Выбор → `brum_hugged` / `tik_stays`. Ставится `arc9_done`.

## Новые имена, места, предметы
Бурлим (десятник), Хельдгрим Железносердый, клан Кованого Корня, Гурра (повариха, жена Гарма), Великий Горн, Новая Печать, Сердце Горы, Страж Печати «Сотня Молотов», железный колокольчик Лирии, «Ключ Нити», первый молот Брума.
Враги/подземелья: `hammer_hall`, `mountain_heart`.

## Флаги (ставятся)
brum_wait/joke, wall_punch, brum_sofa, king_sofa, asked_helg_direct, smith_scouting, skill_smith, brum_thanks_plain, brum_court_smith, helg_open/refused/alt, brun_held_hand, brun_cloak, brun_stay, helg_confronted, masters_thanked, seal_fix, seal_close, helg_persuaded, helg_slain, arc9_helg_alive, arc9_helg_dead, has_thread_blueprint, brum_hugged, tik_stays, arc9_done.

## Отношения
- Брум: loy высокий (≈ +25); остаётся в Кархоле кузнецом.
- Брунхильд: aff + (особенно при `brun_held_hand`); слегка падает при `helg_slain`.
- Гарм женат на Гурре (loy +6); Гурра едет с Ротой.
- Ямира, Мирэль, Касси, Нокс — мелкие плюсы.

## Открытые нити
- Ключ Нити: нужна «слеза, пролитая добровольно». Брум куёт.
- Почерк Аурелия («Мы подождём») на лазейке Печати; Ильвара знает больше, чем говорит.
- Король слышит «третий», невидимый колокол.
- Хельдгрим при `helg_persuaded`: три месяца срока.
- Наблюдатель в тёмной сутане на пиру.
- Дальше: север, город молчащих колоколов (арка 10).
