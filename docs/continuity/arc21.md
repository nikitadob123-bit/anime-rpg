# Арка 21 «Мост Через Пустоту» (главы 201–210) — континьюити (автор w4)

## Что произошло
- 201: Утром мост из серебряной нити опускается к шпилю Собора. Орвин остаётся в столице. Проводницы идут с отрядом (Эльвира/Ульрика, Селестина/Корвина); Фиора/Адела остаётся в приюте, дарит пироги. Каждый шаг по нити — нота колыбельной «Утро встанет и без тебя». Ильвара идёт первой. Азура присоединяется (`azura_joined`). Тик плетёт верёвку из бесконечных прутьев (`tik_rope_grown`); выбор `rope_tied / rope_free`.
- 202: Мост Безымянных: души молча машут. Безымянный худощавый учитель с тёплой улыбкой (учитель Короля, имя трёхсложное, не названо), безымянный рыцарь без герба предупреждает Скрила. Выбор `teacher_stop / teacher_pass`.
- 203: Остров Забытых Имён: табличек без счёта, 12 табличек с нарисованной улыбкой. Табличка «Лирия» почерком самого Короля, на обороте «Л + З», шепчет голосом Лирии (`tablet_neck / tablet_bag`). Надпись: мост построили боги, чтобы Король не дошёл до Колыбели без согласия (`bridge_gods_known`). Нокс в восторге, Касси нашла «Пушок», Гарм «Борщ».
- 204: Станция Перевозчика: серый плащ, лодка «без берега» появляется только после платы, ложь пробивает борт, золото и бомбы падают в бездну. Книга: двенадцать записей имени первого учителя; долг оплачен им (`teacher_name_paid`). Выбор `ferry_asked / ferry_blind`.
- 205: Цена имени: Тик «Бесёнок-в-бутылке», Касси «Магистр Взрывных Наук», Скрил «Хельд» (`skril_gave_held`), Брунхильд «Щитоносица Первого Круга», Нокс — номер читательского билета, Мирэль «Тряпка», Король — самое дорогое прозвище (`nickname_paid`). Выбор `nickname_ilvara_keeps / nickname_ilvara_says`. Концепт `concept_price_of_name`: потеря усиливает удар (+40% резонанса).
- 206: Азура и Ильвара: лодка, Азура сидит рядом с Королём, Ильвара не знает, куда девать руки («алкоголь на борту запрещён — я ввела!»), ставки Веспера, Король «любуется туманом». Выбор `azura_honest / azura_pretend`. Азура призналась: проверяла Ильвару всерьёз. Флаги `ilvara_jealous`, `azura_tease_done`.
- 207: Лодка без берега: Тик ловит Звёздную Плотвичку, табличка шепчет, во сне Лирия называет прозвище **«Кисель»**. Выбор `kisel_on_hand / kisel_with_lirya`. Перевозчик требует плату за прибытие (чужое имя), поединок — единственный отказ (`ferry_duel_accepted`).
- 208: Бой на причале (подземелье `ferry_station`, босс `ferryman`). Выбор `ferry_mirror / ferry_tags`. Победа: механизм согласия сломан отказом. Выбор `ledger_burned / ledger_kept` (книга Перевозчика). Флаг `ferry_defeated`.
- 209: Порт Предела: пустые причалы, кухня Гарма, одинокий колокольчик на мачте (колокольчики Кругов: двенадцать вешали, тринадцатый — Короля). Выбор `bell_hung / bell_kept`. Азура прощается: послу нельзя на Престолы, остаётся в порту; за ней один танец (`azura_stays_port`).
- 210: Перевозчик (Первый, кто отказался платить) возвращает имена всем (Хельд, Бесёнок и т. д.), «Кисель» тоже. Одно имя не вернуть: **ваше имя записано на ком-то из близких** (кто — не раскрыто; Перевозчик не знает). Выбор `ledger_asked / ledger_trust`. Билет на Предел «Один проезд. Туда». Вдали гора из мечей — Престол Меча. Флаг `arc21_done`.

## Новые имена/места/предметы
Перевозчик (лицо — усталый немолодой человек), Азура (красное платье, зонтик, 17 имён, остаётся в Порту), Мост Безымянных, Остров Забытых Имён, Станция Перевозчика, Порт Предела; табличка «Лирия» (на обороте «Л + З»); верёвка Тика; Звёздная Плотвичка; Билет на Предел (ключевой предмет); подземелье `ferry_station` (ур. 77).

## Отношения
- Ильвара (gen1): ревность к Азуре, объятие с Азурой, держит Короля за руку; aff растёт в 201, 206, 209, 210.
- Скрил: имя «Хельд» возвращено, «рыцарем был и без него». Тик, Гарм, Брум, Грак, Веспер: loy+ в 205, 208, 210. Касси подружилась с Азурой.
- Эльвира/Селестина (Ульрика/Корвина): служебные имена, платить не обязаны; остаются в отряде.
