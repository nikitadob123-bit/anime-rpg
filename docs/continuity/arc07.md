# Арка 7 «Пески Сожжённых Часов» (главы 61–70) — автор w2

## Что произошло
- 61: отряд входит в Хар-Сетру (песок идёт против ветра). Верблюд Султан плюёт в Короля; Рота Хозяина разулась («ботинки на шею»). Лирия через колокольчик велит надеть шляпу. Выбор пути → `path_yamira` / `path_map` / `path_ilvara`.
- 62: Нур-Хазар, город клана Мурр (террасы, 109 ступеней, фонари). Ямиру встречают как беглянку и героиню. Рынок контрактов, Король покупает подушку с кошкой. Матриарх Сафира (тётя Ямиры) поит чаем, шутит про любовь Ямиры. Выбор → `safira_wait` / `safira_together` / `safira_ask`.
- 63: Зал Договоров. Договор №4417 «Король Демонов», 3000 золотых, заказчик безымянный (печать — золотой колокол в венке, догадка: Церковь). Ямира стояла над спящим Королём 9 минут с ножом; он бормотал «Лирия, положи ложку… не уходи». Король просит еды. Выбор → `contract_torn` / `contract_kept` / `contract_rewritten` («кормить Короля до костра или дольше»).
- 64: Оазис Серебряной Змеи (вода течёт вверх, змеи поют, рельеф уробороса). Гарм находит орка-повара клана Хар-Зуул («Ест?» «Ест.»). Лирия: «Не забыл про завтрак?». Крыша караван-сарая, один плащ на двоих. Выбор → `yamira_bond` / `yamira_tease` / `yamira_silent` (aff Ямиры +4…5).
- 65: Руины Часового города (бой: Колосс, подземелье `clock_ruins`). Скрил находит табличку прадеда «Скрил-старший, носильщик часов Девятого цеха», тот «не возражал» против сожжения часов. Табличка с почерком, похожим на почерк Ильвары. Выбор → `clock_dismantle` / `clock_preserve`. Ставится `has_clock_map` (Карта Часового города: путь к Песчаному трону).
- 66: Хаш-Намур зовёт из песка, знает Ильвару, Мирэль («дочь Хромого Клыка»). Ильвара признаётся: десятый генерал первого Круга, имя вычеркнуто по приказу (в т.ч. её). Оговорка «каждый Круг». Созвездие-колокол («Колокольня»), 47 звёзд. Выбор → `hash_sleep` / `hash_now` / `hash_ask_ilvara`.
- 67: Песчаный трон из часов. Хаш: Совет Часов сжёг часы, чтобы остановить Круг, но остановил только себя. Предложение: власть над пустыней + согласие сжечь 12 Башен Времени. Король засыпает посреди ответа. Выбор → `hash_refuse` / `hash_tempted` / `hash_probe` (Хаш хочет покоя, ему одиноко).
- 68: бой `mirage_dunes` (Владыка Миражей). Король узнаёт настоящих по привычкам; мираж Лирии разоблачён («Лирия не говорит „рада тебя видеть“ — она спрашивает про завтрак»). Новая сила «Приказ тишины» (`skill_silence_order`). Выбор теста → `mirage_test_food` / `_speech` / `_hug`.
- 69: бой `sand_throne`, Хаш-Намур; Ильвара входит в зал (Хаш научил её считать ступени). Дуэль: `hash_freed` (освободить, aff Ильвары +5) или `hash_killed` (Ильвара −4 loy, −2 aff).
- 70: Совет Мурр оправдывает Ямиру; договор №4417 недействителен. Выбор → `clan_murr_all` / `clan_murr_scouts`. Разговор с Ильварой на крыше (положила голову на плечо). Созвездие-колокол; Веспер: флот Церкви (13 кораблей, адмирал Торвальд) идёт к Жемчужному Архипелагу. Ривэй слышит зов Прилива. Ставится `arc7_done`.
