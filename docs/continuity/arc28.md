# Арка 28 «Колыбель Первого Часа» (главы 271–280) — канон (автор w6)

## Что произошло
- 271: Врата Колыбели. Боги стоят у входа (Аурелий, Тарн, Иссель; Вальдор — живой при `spared_valdor`, серебряной нитью в мече Брунхильд при `killed_valdor`; Миара — свеча-дух). Выбор: `a28_gate_front` (главный вход) / `a28_gate_sneak` (замок Ямиры).
- 272: Аурелий не лжёт. Хельмор не стёрт — перенесён в Изнанку целиком с людьми, они спят. Чай, соль Гарма. Выбор `a28_tea_drunk` / `a28_tea_refused`.
- 273: Тринадцатый Круг: план — Лирия вернётся, мир забудет всё; Лирия стареет вместе с Кругом. Выбор `a28_tempted` / `a28_plan_refused`.
- 274: Зал Первого Звона: первые слова отряда, «два крика в одном звуке». Выбор `a28_asked_ilvara_sound` / `a28_dont_ask`.
- 275: Ложе. Встреча с Лирией, прозвище герою возвращено без текста (`lyria_nickname_back`). Выбор `a28_first_sorry` / `a28_first_bread`.
- 276: Лирия: «Я не жертва». Прозвища отряду (Огонёк — Мирэль, Счётная Книга — Нокс…). Предупреждение о цене Колыбели. Выбор `a28_promise_stay` / `a28_promise_ask`.
- 277: Девять отвечают «да» по одной (сначала развилка `heard_nine` — молча слушать / `decided_alone` — решил за них). Ильвара: «нет» — плану, «да» — герою («я не считаю ступени, я просто иду»). Касси сказала «Я вас люблю. Всех.»; Сэра говорит без заикания. aff +3 каждой, +4 Ильваре.
- 278: Аурелий против. Боги отходят, Тарн секундант. «Форма прощения номер семь» (извинение заранее). У Ильвары в сумке копии всех форм. Выбор `a28_aurelius_heard`/`a28_aurelius_cut`; обещание Лирии `a28_vow_mercy` / `a28_vow_none`.
- 279: Бой в Сердце Колокола (`heart_bell`, босс `aurelius`). Герой не бьёт, а звонит в колокольчик Лирии; Ильвара принимает звон на «сорок седьмой ступени». Дуэль: `a28_aurelius_spared` (форма №8) / `a28_aurelius_bound` (перо и печать отобраны). Аурелий не убит ни в одной ветке. Лирия и Аурелий звонят вместе.
- 280: Колокол «висит» — не звонит и не останавливается. Завтрак всех, Аурелий впервые ест хлеб Гарма. Боги слышат страх — сумма страха пяти богов складывается в «Единого». Свеча Миары успевает: «Он из нас… Единый… не стреляйте». Выбор `a28_i_will_ring` / `a28_think_together`. С востока идёт армия теней. Финал: «Война началась».

## Имена и места
Колыбель Первого Часа, Зал Первого Звона, Ложе Лирии, двенадцатилепестковый золотой круг (тринадцатый лепесток пуст). Колокольчик Лирии на ленте — у героя. Подземелье `heart_bell` (ур. 94), враги `bell_seraph chime_guard peal_wraith bell_verger aurelius`.

## Нити для арок 29–30
- Колокол завис; цена Колыбели: Лирия или мир. Лирия готова заменить Колокол (арка 29, гл. 286: герой отказывается → `refused_price`).
- Единый — страх пяти богов. Миара пыталась его остановить.
- Аурелий жив, перешёл на сторону отряда, учится завтракать.
- Тик: розовое зелье. Скамья/двор Вальдора — зерно «Скамьи во дворе».
