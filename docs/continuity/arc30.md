# Арка 30 «Выбор» (главы 291–300) — финал, канон (автор w6)

## Что произошло
- 291: Утро после победы. Лирия — седая прядь, ~40 лет по телу, больше не стареет. Ильвара просит выслушать «Слова». Выбор `a30_age_joke`/`a30_age_plain`.
- 292: Слова девяти. Ответ героя одним словом: Мирэль «Спорим?», Нокс «Округляю.», Сэра «Громко.», Ямира «Мурр.», Брунхильд «Рядом.», Ривэй «Прилив.», Касси «Взрыв!», Морвена «Любопытно.», Ильвара «Комплимент.». Три выбора «останься»: `heart_gen1..9`, `heart_any`; при выборе одной остальные не предлагаются (`heart_open` гасится на -1). Никому → `heart_family`.
- 293: Слова шестерых (Тик начинает; Грак — маршал). Выбор подарка: `a30_gift_inn` (трактир Гарма/Тика) / `a30_gift_guard` (Караул Хельмора) / `a30_gift_free`.
- 294: Три героини (spared_*/killed_* → Эльвира/Ульрика, Селестина/Корвина, Фиора/Аделаида). Выбор `a30_pardon_selestina`/`a30_sel_service`; меч Эльвиры: `a30_sword_hero`/`a30_sword_mirel`.
- 295: Лирия на крыше Колыбели. Пирожок (`toy_pirozhok` → `a30_pirozhok_returned`). Описание четырёх путей. Выбор: `own_choice` (два варианта) или `lyria_refused_decide`.
- 296: Четыре двери. Люмиэль — Привратник Порога (бывший Апостол Света), подсказка: «три пощады, один слух, одно слово, одно сердце». Выбор вещи: `a30_carry_bell/crown/bread/none`.
- 297: Выбор. `true_ready` = spared_fiora + spared_elvira + spared_selestina + heard_nine + own_choice + heart_any; иначе `true_blocked`. Концовки: `ending_return`, `ending_dim`, `ending_crown`, `ending_true`.
- 298: Новый Хельмор (ветки по концовкам + 9 романтических сцен `heart_genN` + `heart_family`). Выбор `a30_house_kitchen`/`a30_apple_tree`/`a30_house_same`.
- 299: Эпилоги девяти и шестерых (Совет Хельмора — Ильвара, «Клуб споров», «Бабах без травм», Школа щита, Музей замков, Дом у воды). Тост `a30_toast_*`. Король спит, никто не будит.
- 300: Двор Коллегии Рассвета, скамья под яблоней, «Братик, вот ты где». `ending_true`: меловая «Сорок восьмая» (Ильвара, `a30_forty_eighth`). Общий завтрак. Титр «Конец / Нимб Мира», флаг `game_complete`.

## Флаги финала
`ending_*`, `heart_gen1..9`, `heart_any`, `heart_family`, `true_ready`, `true_blocked`, `own_choice`, `game_complete`.
