# Спецификация главы «Нимба Мира»

Как писать главы сюжета (всего 300 = 30 арок × 10 глав). Документ — контракт для параллельных авторов: каждая арка лежит в своём файле `js/story/arcNN.js` и подключается движком автоматически.
Сюжетный план — `docs/STORY_BIBLE.md` и `js/story/outline.js`.

## 1. Эталон длины главы (измерено по текущей игре)

«Глава» в текущей игре = всё, что игрок читает между двумя «Продолжить» главного сюжета: несколько сцен `chN_a…`, дуэли и вступление к боссу. Реплика = строка вида `[говорящий, текст, настроение]` (служебные строки не считаются). Измерения: `node tools/story-stats.js`.

| Единица | Сцен | Реплик | Знаков | Слов | Выборов |
|---|---|---|---|---|---|
| Пролог | 1 | 105 | 10 738 | 1 793 | 1 |
| Глава 1 (ch1_a, ch1_b) | 2 | 53 | 5 183 | 862 | 0 |
| Глава 2 (ch2_a, ch2_b, ch2_c + дуэль Фиоры) | 3 + 1 | 98 | 9 228 | 1 519 | 4 |
| Глава 3 (ch3_a…ch3_d, ch3_end + pre + 2 дуэли) | 5 + 3 | 138 | 12 382 | 2 039 | 3 |
| **Среднее по главам 1–3** | 3 | **≈ 96** | **≈ 8 900** | **≈ 1 470** | ≈ 2.3 |

Дополнительно: средняя реплика ≈ 95 знаков (максимум ≈ 365); сцена — 14–36 реплик (в среднем ≈ 22); рассказчик (`n`) — 20–25% реплик; настроение указано примерно у 55% реплик; бой — 0–3 подземелья на главу. Один «заход» читается 8–12 минут.

**Стандарт новой главы:** 90–110 реплик, 8–10 тыс. знаков (≈ 1 400–1 700 слов), 3–4 сцены по 18–36 реплик, 1–2 выбора (линтер допускает 1–4), 0–1 бой, награда, флаги, романтическая или дружеская вставка (`aff`/`loy`), юмор в духе Араты. Главы 4–10 арки 1 написаны по этому стандарту (≈ 100 реплик, ≈ 8 000 знаков).

Пороги линтера: **ошибка**, если реплик < 70 или > 180, знаков < 6 000 или > 15 000, выборов < 1 или > 4, сцен < 2 или > 6; **предупреждение**, если реплик < 85, знаков < 7 500, рассказчика > 40%, настроений < 30%, нет `aff`/`loy`, нет `set`.

## 2. Что входит в главу (обязательные элементы)

1. **Заставка** `['title', 'Глава N', 'Подзаголовок']` — в начале каждой сцены (движок вставляет сам, если её нет). В последней сцене можно добавить свою `['title', 'Заголовок финала', 'Куда дальше']` (например, «Конец арки» в 10-й главе арки).
2. **3–4 сцены** (`scenes`), у каждой `bg` (фон) и `sub` (подзаголовок).
3. **1–2 выбора** (`['choice', [{ t, f, r }…]]`), каждый вариант ставит флаг `f` и отвечает реакцией `r`.
4. **0–1 бой.** Привязка к подземелью из `D.DUN` (`battle: { dun }`): сцена `afterBattle` играется после победы над боссом; `pre` — сцена перед боссом (внутри вылазки); `duels` — дуэль «пощадить / убить» с врагом, у которого поле `duel`.
5. **Награда** `reward: { gold, sp?, mats?, cons? }` — движок сам добавляет `give` в последнюю сцену.
6. **Флаги** (`set`, `f`) — минимум один сюжетный; движок сам ставит `chN_done`.
7. **Романтическая/дружеская вставка:** `aff` (для генералов и героинь) или `loy` (лояльность свиты).
8. **Юмор в духе Араты** — см. список мотивов в `docs/STORY_BIBLE.md` §6.3.

## 3. Формат реплик

```js
['n', `Текст рассказчика. Можно {name}.`],          // рассказчик (без портрета)
['h', `Реплика героя.`, 'h'],                       // говорящий, текст, настроение (необязательно)
['i', `Реплика Ильвары.`, 'n'],
```

- Говорящие (`D.SPEAKERS`): `n` рассказчик, `h` герой (`{name}`), `l` Лирия, `i` Ильвара, `m` Мирэль, `x` Нокс, `s` Сэра, `y` Ямира, `b` Брунхильд, `r` Ривэй, `c` Касси, `v` Морвена, `e` Эльвира, `t` Селестина, `f` Фиора, `a` Люмиэль, `g` Грак, `k` Скрил, `q` Тик, `w` Гарм, `z` Веспер, `u` Брум, `p` Проповедник, `?` неизвестный. Персонажи без портретов (Регент, Привратник, боги и т. д.) — в `js/story/cast.js`; полный список: `node tools/lint-story.js --list`.
- Настроения: `n` нейтрально, `h` радость/ухмылка, `a` гнев, `s` смущение, `d` печаль, `m` облик Короля (для героя).
- Подстановки: `{name}` — имя героя, `{echo}` — название Эха героя.
- Текст в обратных кавычках; кавычки-ёлочки «» и тире — в тексте; `…` вместо `...`.

### Служебные строки

| Строка | Смысл |
|---|---|
| `['bg', id]` | сменить фон (id — `RPG.story.BG`; список — `lint-story --list`) |
| `['cg', 'halo_city' \| 'demon_king' \| null]` | CG на весь экран |
| `['fx', 'stars'\|'embers'\|'fireflies'\|'snow'\|'silence'\|'flash'\|'entropy'\|'halo'\|'shake'\|null]` | эффект |
| `['title', 'Заголовок', 'Подзаголовок']` | карточка-заставка |
| `['hide', ключ]` | убрать спрайт говорящего |
| `['set', { флаг: значение }]` | поставить флаг (числа складываются) |
| `['give', {gold, sp, cons, mats, item}]` | выдать награду (в обычных главах — только через `reward`) |
| `['rec', 'gen2']` | принять в Свиту |
| `['loy', { gen6: 3 }]`, `['aff', { gen1: 4 }]` | лояльность / романтика (от −10 до 10) |
| `['if', 'флаг', [строки…]]` | показать строки, если флаг поставлен |
| `['choice', [{ t, f, r }, …]]` | выбор: `t` текст кнопки, `f` флаги, `r` строки-реакции |

## 4. Контракт главы

```js
// js/story/arc02.js — арка 2 (главы 11–20)
(function () {
  const RPG = globalThis.RPG, D = RPG.D, C = D.CHAPTERS;

  C[11] = {
    title: 'Падение в розы',                 // совпадает с outline.chapters[10].title
    scenes: [                                // 2–6 сцен; ids: ch11_a, ch11_b, …, ch11_end (последняя)
      { sub: 'Приземление', bg: 'garden', lines: [ /* реплики */ ] },
      { sub: 'Тихий приют', bg: 'garden', lines: [ /* … */ ] },
      { sub: 'После боя', bg: 'garden', afterBattle: true, lines: [ /* … */ ] }   // играется после победы над боссом battle.dun
    ],
    battle: { dun: 'garden_hall' },          // необязательно: id подземелья из D.DUN (добавьте через RPG.story.defineDungeon)
    pre:    { garden_hall: { sub: 'Перед боссом', bg: 'garden', lines: [ /* … */ ] } },   // необязательно
    duels:  { sister_matron: { sub: 'Дуэль', bg: 'garden', lines: [ /* choice пощадить/убить */ ] } },   // необязательно
    intro:  { garden_hall: [ /* реплики-вступление к вылазке */ ] },                                  // необязательно
    reward: { gold: 700, sp: 1, mats: { ess_l: 3 }, cons: { pot_hp2: 2 } }                            // обязательно
  };
  // …
})();
```

Что делает движок (`js/story/core.js`, `RPG.story.install(n)`) после загрузки файла:
- создаёт сцены `D.SCENES['ch11_a']…['ch11_end']` и записи `D.STORY` (`need.done` — предыдущая сцена главы / последняя сцена предыдущей главы);
- в начало каждой сцены добавляет `title` «Глава N» (если вы не добавили сами), в последнюю — `set {chN_done: 1}` и `give(reward)`;
- для `afterBattle`: сцена открывается после победы над боссом (`need.clear = battle.dun`), сцена перед ней становится «воротами»: подземелье открывается, когда сыграна сцена-ворота и пройдено подземелье `d.need`;
- регистрирует `D.PRE_BOSS`, `D.DUEL_SCENE`, `D.INTROS`.

**Прогресс** хранится как раньше: `slot.story.done` (id сыгранных сцен) и `slot.story.flags`. Глава считается пройденной, когда сыграна её последняя сцена (`chN_end`, для глав 1–3 — `ch1_b`, `ch2_c`, `ch3_end`). Новых полей в сохранении нет, поэтому старые сохранения (v1–v4) работают без миграции: игрок, прошедший ch3_end, оказывается в главе 4. **Нельзя менять id сцен уже вышедших глав.**

Подземелья и враги (`js/story/enemies.js` или файл вашей арки):
```js
RPG.story.defineEnemy('cloud_hound', { n: 'Облачная гончая', ic: '🐕', role: 'skirm', tags: ['beast'], sk: ['e_bite', 'e_zap'], weak: ['fire'], res: ['bolt'], loot: [['fang', 0.4, 1, 2]] });
RPG.story.defineDungeon({ id: 'stairs', n: 'Лестница Часов', ic: '🪜', lv: 16, floors: 2, bio: '…', col: '#7aa0e0', d: 'Описание', pool: ['cloud_hound'], mini: 'bell_knight', boss: 'step_warden',
  need: 'cathedral', gate: '#pending', lockHint: 'Почему закрыто (показывается игроку)' });
```
`gate: '#pending'` движок заменит на сцену-ворота. Роли (`role`), навыки (`D.ESK`) и формулы боя не меняйте — только данные.

## 5. Загрузка арок

- `index.html` грузит только ядро (`cast.js`, `core.js`, `enemies.js`, `ui-story.js`). Арки грузятся лениво: при входе в игру `ST.ensureFor(slot)` подгружает `outline.js` (для арок > 1), арку текущей главы (`<script src="js/story/arcNN.js">`), а затем предзагружает следующую.
- Файл арки написан, если в `outline.arcs[k-1].ready` > 0. Когда пишете арку: заполните `ready` (число написанных глав), иначе линтер выдаст ошибку, а вкладка «Сюжет» покажет главы «скоро».
- Service worker (`sw.js`) кэширует арки по мере показа (`/js/story/arcNN.js`); в прекэше только арки 1–2. Когда появится `arc02.js`, добавьте его в список `ASSETS` и поднимите `VERSION`.
- Новые фоны: `RPG.story.bg(id, [верх, середина, низ], 'r,g,b')` в `cast.js` (CSS-градиент подключается автоматически). Новый говорящий: `RPG.story.speaker(id, { n: 'Имя', c: '#цвет', art?: 'id портрета' })`.

## 6. Как писать арку (пошагово)

1. Откройте план арки в `docs/STORY_BIBLE.md` (раздел «Арка N») или `js/story/outline.js` (`D.OUTLINE.arcs[k-1]`, `chapters[n-1]`): название, summary, фон, cast, уровень, босс.
2. Создайте `js/story/arcNN.js` (шаблон выше); напишите 10 глав. Копируйте тон из глав 4–10 (`arc01.js`).
3. Если нужен бой — добавьте врагов/подземелье (`defineEnemy`/`defineDungeon`), используйте существующие навыки `D.ESK`, уровни около `RPG.story.levelOf(n)`.
4. В `outline.js` проставьте `ready: 10` для арки; если по ходу меняете план — правьте `outline.js` и запустите `node tools/gen-bible.js`.
5. Проверка:
   ```bash
   node tools/lint-story.js --arc 2          # формат, id, длина, русский язык, запрещённый контент, флаги
   node tools/lint-story.js                  # всё, включая outline (должно быть: ошибок 0)
   node tools/story-stats.js                 # длина каждой главы vs эталон
   npm test                                  # юнит-тесты + test/story.js
   node tools/e2e-story.js                   # e2e: вкладка «Сюжет», главы 4–10, вылазки, сохранение
   ```
6. Перед пушем: `git pull --rebase`, маленькие коммиты (одна арка или несколько глав за раз), `git push origin main`. После деплоя проверьте `curl -I https://nikitadob123-bit.github.io/anime-rpg/js/story/arcNN.js` → 200.

## 7. Чек-лист главы

- [ ] 90–110 реплик, 8–10 тыс. знаков, 3–4 сцены, `title` в каждой сцене
- [ ] 1–2 выбора с флагами и реакциями; флаги, на которые есть `if`, где-то ставятся
- [ ] `aff` или `loy` есть; смешная сцена с мотивом из библии (дремота, «Вернее…», «Мурр.», «Вероятность…»)
- [ ] бой привязан к существующему подземелью/боссу; `afterBattle` после боя; `pre`/`duels` по необходимости
- [ ] `reward` скромный, растёт с главой; расходники/материалы существуют (`lint-story --list`)
- [ ] нет откровенных сцен, мата, латиницы; кириллица ≥ 90%
- [ ] имена и канон не противоречат `STORY_BIBLE.md`
- [ ] `node tools/lint-story.js` и `npm test` зелёные
